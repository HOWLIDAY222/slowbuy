# 慢半拍 · 冲动消费冷静器

一个无需安装依赖的静态网页工具。买之前，先预演使用成本、换算工作时间，再对比自己的储蓄目标。

## 功能

- 时间账：按到手收入和工作时间换算商品的时间成本。
- 使用账：预演使用 3、30、100 次的单次成本，计算达到个人成本标准需要使用多少次、多少周。
- 另一种选择：对比把同一笔钱留给个人目标后的假设进度。
- 心动账单：预览账单、下载 PNG 图片、复制文字；账单不展示收入数字。
- 冷静清单：保存购买理由，选择冷静期，复盘决定，支持移除和撤销。

## 直接使用

用现代浏览器打开仓库根目录的 `index.html`。该文件包含完整样式和脚本，也可以单独上传到静态托管平台。

## 修改和构建

需要 Node.js，无需 `npm install`。

```sh
node build.mjs
```

这会重新生成 `dist/script.js`。将 `dist/` 作为静态网站的输出目录即可。

生成包含所有资源的单文件版本：

```sh
node build.mjs index.html
```

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 可直接打开和发布的单文件版本 |
| `dist/index.html` | 多文件版页面模板 |
| `dist/styles.css` | 样式与响应式布局 |
| `dist/core.mjs` | 计算、输入校验和记录解码 |
| `dist/app.js` | 场景交互、清单和账单导出 |
| `dist/script.js` | 生成的浏览器脚本 |
| `dist/favicon.svg` | 网站图标 |
| `build.mjs` | 生成静态脚本和单文件版本 |

## 数据说明

清单仅保存在当前浏览器的 localStorage。没有服务器端数据库或账户同步。收入只用于当前页面计算，不上传、不保存。换算与目标进度是依据输入数据的试算，不等同于实际支出、节省金额或已经完成的储蓄。

冷静倒计时在重新打开页面时按实际经过的时间更新，不会发送外部通知。更换设备、清除浏览器数据或使用无痕模式可能导致记录丢失。

## 发布

可直接上传根目录的 `index.html`，或部署整个 `dist/` 目录。使用支持构建命令的静态托管平台时，构建命令为 `node build.mjs`，输出目录为 `dist`。

### GitHub Pages

在仓库的 `Settings → Pages` 中，将 Source 设为 `Deploy from a branch`，选择 `main` 分支和 `/(root)`，然后保存。根目录的 `index.html` 是完整的单文件版，无需额外构建；`.nojekyll` 用于直接提供静态文件。
